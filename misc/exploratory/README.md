# Exploratory scripts

`variance_test_datasets.py` is an ad-hoc, interactive comparison of one UMM and
one MAINZ cirrhosis dataset. It is not imported by the pipeline and intentionally
retains its historical relative paths and plotting behavior.

The original `src/variance_test_datasets.py` entry point remains as a
compatibility wrapper. Run it from `src/`, as before, to preserve the script's
working-directory-dependent data paths.
